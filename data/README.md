# data/

| Folder | Contents |
|---|---|
| `douala/` | `pilot_survey/` (RTK + phone building survey of Bonamoussadi), `iuc/` (IUC workshop rasters/spreadsheets and Dountsop building footprints). |
| `fotouni/` | `pilot_survey/` (RTK + phone building survey, with photos) and `town_survey/` (complete town survey with phones only). |
| `imu/` | Phone IMU + GPS recordings of car drives, March 2026 (road-quality tests). |
| `trip_photos/` | Photos from the Cameroon trip (not tracked in git). |
| `building_datasets.md` | Methodology for building the pilot-survey datasets. |
| `survey_maps_index.html` | Dropdown page showing the pilot-survey maps (generated by `code/building_survey`). |

Some data is duplicated into the code repos that need it (see each repo README); this folder is the master copy.
