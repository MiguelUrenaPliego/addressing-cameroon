# fotouni/town_survey

Complete survey of the town of Fotouni with the EFYL phone app (August 2026).

| Folder | Contents |
|---|---|
| `survey_app/` | Data exported from the survey app: `exports/` (daily admin CSV exports, cumulative), questionnaire PDF, project snapshot zip. |
| `streets_places/` | Street names, missing streets and important places: edge/street edit tables, KML of places, abbreviation and squares/intersections/facilities spreadsheets. |
| `osm/` | Data downloaded from OpenStreetMap (street networks etc.). |
| `quality_control/` | Output of `code/fotouni_town_qc` (reports, maps). |

Personal data (contact names/phones) is present in `survey_app/` - not tracked in git.
