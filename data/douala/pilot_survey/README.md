# douala/pilot_survey

Pilot study, Bonamoussadi (Douala). Buildings/points surveyed with RTK GNSS receivers and phones in SW Maps.

- `raw/block_1`, `raw/block_2` – raw SW Maps `.xlsx` exports (RTK and phone pairs).
- `douala.csv` – merged dataset built by `code/building_survey/build_douala.py` (717 rows).
- `streets.gpkg` – street network the survey map is drawn on.
- `survey_map.html` – interactive survey map.

Methodology: `../../building_datasets.md`.
