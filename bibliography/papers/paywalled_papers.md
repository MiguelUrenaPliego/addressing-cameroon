# Papers cited but not locally available

These are cited in `main.tex` (bib keys already added to `references.bib`
from bibliographic memory, not from having read the source) but I have not
actually read the source myself. Please double-check the citation details
below against the real publication, and send the PDF if you have
institutional access, so the citation can be verified before submission.

## `dale1999landadmin`
Dale, Peter F. and McLaughlin, John D. (1999). *Land Administration*.
Oxford University Press.
Used to support the claim that cadastral/land-parcel-boundary work has a
much stricter positional-accuracy requirement than street addressing,
since parcel area error scales with boundary positional error.

## `enemark2014fitforpurpose`
Enemark, Stig; Bell, Keith Clifford; Lemmen, Christiaan; McLaren, Robin
(2014). *Fit-For-Purpose Land Administration*. Joint FIG/GLTN/World Bank
publication.
Used to support the "incrementally improvable, community-validated spatial
framework beats waiting for a complete formal cadastre" argument used to
frame the addressing pipeline's five-step deployment procedure, and the
official-adoption discussion in Section "Step 5". This one is usually
freely downloadable from the FIG/GLTN/World Bank sites, but flagging here
in case the exact edition/pagination needs checking before citing specific
claims from it.
